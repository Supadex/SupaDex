# Runbook: governance roles, delays, cancellation (ADR-0010)

Status: draft for review. PRODUCTION READINESS NOT ESTABLISHED.

- **Delay floor:** `SupaTimelock.delayFloor` is immutable. It is 48 h on every chain except the listed local and test chains (1 h there). Neither the constructor nor `updateDelay` accepts less. Unknown chains get 48 h (fail-safe). The verifier also requires `minDelay ≥ 48 h` on value-bearing profiles. Note: Edith 10-A proposed a constructor parameter. This implementation derives the floor from chain id instead, so a deployer cannot pass a short floor. To review: whether the test-chain list is acceptable.
- **Role holders:** on value-bearing profiles, PROPOSER, EXECUTOR, CANCELLER, GUARDIAN and OPERATOR must be Safe-style multisigs. The verifier checks code, `getThreshold() ≥ 2` and `getOwners().length ≥ threshold`, and requires GUARDIAN ≠ PROPOSER. Including OPERATOR in this check is a strict reading of "every role holder" and can be relaxed if Edith prefers.
- **Canceller veto / liveness risk (10-D):** a canceller can cancel every queued operation indefinitely. That is a liveness veto by design, because cancellation is the defence against a malicious proposal. If the canceller set is compromised or uncooperative, governance cannot make progress. Last-holder protection means a canceller cannot be removed without a timelocked op, which the canceller can itself cancel. **Recovery is a redeploy**: deploy a fresh stack, then pause the old vault through the guardian (exits stay open) and migrate liquidity. Mitigations: keep the canceller a high-threshold Safe whose signers differ from the proposer's, and monitor `CallCancelled`.
- **Ownership transfers** are single-step (owner = timelock). A 2-step transfer (10-E) is not implemented. It is low priority because the transfer itself is a timelocked op.
- **Salt recovery:** `schedule` emits `CallSalt(id, salt)` next to `CallQueued`, so Safe-wrapped schedules can be executed from logs alone. `isOperationExpired(id)` distinguishes expired from never-scheduled.
- **BIN curve:** it is paused at genesis on value-bearing networks (`CircuitBreaker.pauseCurve(1)`) and the verifier checks this. Unpausing is a timelocked op that requires Jexi's sign-off and an external audit.
